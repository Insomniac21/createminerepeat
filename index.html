Ajouter le serveur dans BedrockAdd the server in Bedrock

  1. Ouvre Minecraft (Bedrock) et touche Jouer.
  2. Va dans l'onglet Serveurs, descends tout en bas et touche Ajouter un serveur.
  3. Nom du serveur : CreateMineRepeat (ou ce que tu veux).
  4. Adresse du serveur : createminerepeat.playit.plus (sans le port).
  5. Port : 3223 (remplace 19132).
  6. Touche Enregistrer, puis touche le serveur dans la liste pour le rejoindre.

Pour Windows, Android et iOS. Consoles (Xbox, PlayStation, Switch) : pas encore testées, viens en parler sur le Discord.

  1. Open Minecraft (Bedrock) and tap Play.
  2. Open the Servers tab, scroll to the bottom and tap Add Server.
  3. Server Name: CreateMineRepeat (or anything you like).
  4. Server Address: createminerepeat.playit.plus (without the port).
  5. Port: 3223 (replace 19132).
  6. Tap Save, then tap the server in the list to join.

For Windows, Android and iOS. Consoles (Xbox, PlayStation, Switch): not tested yet, ask us on Discord.
